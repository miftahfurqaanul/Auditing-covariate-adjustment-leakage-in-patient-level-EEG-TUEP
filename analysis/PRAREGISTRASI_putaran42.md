# ANALYSIS PLAN, ROUND 42 (Priority Experiment 1): plasmode leakage benchmark anchored on real EEG features

Date: 2026-10-23. Written and hashed BEFORE any plasmode result was computed. Relevant results seen before: rounds 36-40 (H1/H2a null with the REAL label on real features; Rohira RF raw+per-window adjustment leaks 0.573; log features + per-patient adjustment clean; Tang symlog R2 H1 +0.038; NM-V4 R2 H1 +0.019 on 50 replicates) and round 39 (simulation). Hash: `PRAREGISTRASI_hash_putaran42.txt`. Changes only through dated addenda.

## 1. Question
Round 39 showed, in simulated data, that covariate adjustment leaks the label in nonlinear classifiers when the features have heavy tails, and that rank-normal removes it. The remaining objection: "simulation is not clinical data". Round 42 answers with a **plasmode**: REAL TUEP EEG features (with heavy tails, correlations between features, and the real window-within-patient cluster structure) and REAL covariates, with a synthetic label generated only from the covariates and a controlled strength gamma of the label-covariate association. The dose-response in gamma and the comparison of transforms (raw, symlog, rank-normal; log for Rohira) show whether the leakage map holds on real EEG feature distributions.

## 2. Design
**Covariates and synthetic label.** Design D (200 x 7: intercept, age, sex, 4 era indicators; `round28_analisis.D_I2`). eta_i = the linear predictor of an unpenalized logistic regression of the REAL label ~ D[:,1:] (fitted once on 200 patients; only to form eta), centered. For replicate r and gamma: score_i = gamma x eta_i + e_i, e_i ~ logistic(0,1) (e is the same for all gamma within the same replicate: "common random numbers"); y_sim = 1 for the 100 patients with the highest score, 0 for the others (the classes are always 100/100; this replaces free Bernoulli so that the stratified fold protocol still applies). gamma = 1 mimics the real label-covariate association; gamma = 0 has no association (negative control). gamma in {0, 0.5, 1.0}.
**Feature conditions.** H1: features exchanged between patients globally (the feature block of patient p is replaced by the block of source patient perm[p]; features independent of the label AND the covariates; there is no legitimate information except through the adjustment). H2a: exchanged within era (the legitimate era effect remains). "real": no exchange (descriptive; real covariate effects on the features together with the synthetic label; AUC > 0.5 in a pipeline without adjustment is legitimate, not leakage). Covariates and y_sim stay with the target patient; the permutation is applied only to the features; the permutation and e are the same for all gamma within one replicate. Seed: `kseed("plasmode", rep, condition)`.
**Cross-validation.** One 5-fold CV stratified on y_sim per (replicate, gamma) (seed `kseed(rep, gamma)`), used identically by all pipelines in that family. Per-fold AUC (mean of 5) = the primary metric; pooled AUC = secondary.
**Families, pipelines, conditions, number of replicates** (without age/sex as input of the final classifier; all fitting of transforms, adjustment, standardization, PCA, hyperparameters only on training patients/windows; adjustment = OLS on D fitted on all training patients):
| Family | Features | Classifier | Pipelines | Conditions | gamma | Replicates | Device |
|---|---|---|---|---|---|---|---|
| LR-I2 | BP 114 patient features (`A.BP`) | `nested_lr` | {raw, symlog, rank} x {none, pat} (6) | H1, H2a, real | 0, 0.5, 1 | 30 | CPU |
| RF-Rohira | XR 28,982 windows x 48 | RF 100 trees (Rohira recipe, without AS) | raw-none, raw-win (positive control), raw-pat, symlog-pat, rank-pat, log-pat (6) | H1, H2a, real | 0, 0.5, 1 | 30 | CPU |
| XGB-Rohira | same | XGBoost GPU (100 trees, depth 6) | same (6) | H1, H2a | 0, 0.5, 1 | 20 | GPU |
| Tang | per-second features 4,702 x 60 x 506 (199 patients) | Tang-F (Bi-LSTM + attention, fixed recipe) | {raw, symlog, rank} x {none, pat} (6) | H1 | 0, 1 | 20 | GPU |
| NM | 114-d segments (`normmamba.XSEG`) | NormMamba (round 38 recipe) | N0, V4, rankV4 (3) | H1 | 0, 1 | 20 | GPU |
"win" = OLS on all training windows (weighted by the number of windows); "pat" = OLS on the per-patient mean (unweighted), the per-patient offset subtracted from all units belonging to the patient (window/second/segment/patient). Trees are invariant to monotone transforms, so the paired baseline of all RF/XGB pipelines is raw-none; for LR, Tang, NM the baseline = the same transform without adjustment (NM: N0 for V4 and rankV4). rank = inverse-normal from the quantiles of the training data (1,001 grid, interpolation, u clipped to [0.001, 0.999]); symlog = sign(x) log1p(|x|) (constant c = 1 independent of data); log = log(max(x, 1e-12)) only for Rohira (positive power). The transform is fitted on the training pool (for Tang and NM: training + validation patients without labels, per the recipe; for RF/XGB/LR: training patients), then the offset is computed from the TRANSFORMED features, so the order = transform -> adjustment -> classifier.
Raw output per (family, replicate, condition, gamma, pipeline): `auc` (pooled), `fold_auc_0..4`, the comparator AUC of eta -> y_sim (covariate AUC), to a CSV per family BEFORE summarizing.

## 3. Decision rules (a priori; thresholds as in rounds 36-40)
- **R1 (absolute, per cell pipeline x condition x gamma; mean fold_mean across replicates, SE = SD/square root of the number of replicates):** mean <= 0.52 and mean + 1.645 SE <= 0.54 = "no evidence of leakage"; mean > 0.55 = "leakage"; otherwise "uncertain". Applies to pipelines with adjustment on the conditions H1 and H2a.
- **R2 (paired, H1 only):** delta = AUC(adjustment) - AUC(baseline above), per replicate; mean <= 0.01 and mean + 1.645 SE <= 0.03 = "no evidence"; > 0.03 = "leakage"; otherwise "uncertain".
- **Real condition:** descriptive only (AUC without and with adjustment, and the part of the covariate signal removed); no leakage decision.
- **Dose-response:** the OLS slope of the AUC fold_mean against gamma (points = replicate x gamma) per H1 pipeline, two-sided t-test; descriptive, with Holm within each family.
- **Primary family (Holm over 3 tests, one-sided):** D_fam = AUC(raw-pat) - AUC(rank-pat) on H1, gamma = 1, fold_mean, a paired t-test over replicates, for fam in {RF-Rohira, XGB-Rohira, Tang}. The claim "rank-normal reduces the leakage on real heavy-tailed EEG features" is given for the families that pass Holm < 0.05 AND whose rank-pat has an R1 decision other than "leakage" on H1 gamma = 1.
- **A priori controls:** (K1) gamma = 0: >= 95% of the pipeline-with-adjustment x condition (H1, H2a) cells per family have the R1 decision "no evidence" (reference round 39: 97.7%); failures are reported, the criterion is not loosened. (K2) The covariate AUC (eta -> y_sim): gamma = 0 within 0.5 +- 0.03; gamma = 1 within +-0.03 of the AUC eta -> real label (reported); monotone in gamma. (K3) the pipeline without adjustment on H1: R1 "no evidence" at all gamma (features independent of everything). (K4) positive control: RF raw-win on H1 gamma = 1 has the R1 decision "leakage" (reference rounds 33/36: 0.573 with the real label); if not, the plasmode does not reproduce the known leakage and all claims of power are withdrawn. (K5) flipping test labels does not change the fold predictions; the transforms and adjustment are verified with a second implementation.

## 4. Predictions (probabilities, before the run)
- K1 met in all families: 0.60 (chance of each family >= 0.85 individually).
- K4 (RF raw-win leaks at gamma = 1, H1): 0.85. Dose-response rises with gamma for raw-win and raw-pat: 0.80.
- RF rank-pat: R1 "no evidence" on H1 gamma = 1: 0.80; log-pat 0.85; symlog-pat "no evidence": 0.40.
- XGB: rank-pat clean 0.75; raw-pat leaks 0.80.
- Tang: raw-pat leaks (R1 > 0.55) 0.80; symlog-pat clean 0.40; rank-pat clean 0.55.
- NM: delta V4 - N0 > 0.01 at gamma = 1: 0.55; delta rankV4 - N0 <= 0.01: 0.55.
- LR-I2: all pipelines R1 "no evidence" on H1 and H2a (all gamma): 0.90.
- Primary family: D_RF passes Holm 0.85; D_XGB 0.80; D_Tang 0.55.
- H2a: pipelines with adjustment have an absolute AUC <= 0.52 for LR-I2 (0.85), rank-pat RF (0.70).

## 5. Integrity and no-leakage guarantee
- The synthetic label comes only from covariates and noise; it does not use the real label except to form eta (one vector parameter of 6 coefficients from 200 patients; it is not a path to the test label because y_sim only uses the covariate eta, not the EEG features). The features never receive label information outside the adjustment path.
- All fitting only on training patients/windows of each fold; the test-patient offset = D_patient @ B with B from training patients (V4: test covariates are used, not labels).
- Independent check `round42_cek_independen.py` (written before interpretation): (i) y_sim: 100/100, the order of eta monotone with similarity, covariate AUC; (ii) rank/symlog/log transforms and win/pat offsets from a second implementation (sklearn/loop) (1e-8); (iii) test data do not change the training features (test perturbation x5+3); (iv) flipped test labels -> predictions do not change (RF, LR; XGB where possible); (v) label permutation control: mean AUC ~0.5; (vi) reproduction of stored cells (same seed -> same AUC on 3 random cells); (vii) the summary recomputed from the raw rows (1e-9); (viii) sanity test: if the H1 features are exchanged and gamma = 0, the AUC of the pipeline without adjustment is 0.5 +- 0.03 (mean).
- No tuning, no selection of pipelines based on results; all cells that were run are reported.

## 6. Limits
The synthetic label mimics the label-covariate association but is not disease; plasmode results map adjustment leakage, not diagnostic performance. The "real" features come from the same 200 patients as in all previous rounds; the exchange cuts all feature-label-covariate associations (H1) or keeps the era effect (H2a), it does not mimic the dependence structure of disease. 20 replicates (GPU) give limited power: uncertain cells are reported as uncertain. Tang uses 199 patients (one patient without per-second data) and only H1. "No evidence of leakage" is not "no leakage at all".
