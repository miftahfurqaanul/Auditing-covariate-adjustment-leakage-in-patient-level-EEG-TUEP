# ADDENDUM 2 to PRAREGISTRASI_putaran40.md (2026-10-23; written after the runs started but BEFORE any result of stages A/C/GB/GC/NM/ROH was seen; only the pilot P and the CPU H40-0 reproduction were seen: maximum pooled-AUC difference 0.000 on 432 rows)

This addendum specifies the implementation of the analysis (script `round40_ringkas.py`) so that no analysis decision is made after seeing results.

1. **Analysis unit and metric.** Per replicate and configuration: `auc` (pooled, identical to round 39) and `fold_mean` = mean of `fold_auc_0..4`. Paired difference delta = AUC(adjustment) - AUC(without adjustment, same pipeline, same replicate); for trees (RF, XGB) the baseline = raw-none (monotone invariance), for the others the baseline = the same transform with adjust=none. All decisions are reported for both metrics; the primary metric of round 40 is `fold_mean`.
2. **R1 and R2** use the parent thresholds unchanged; R1 on cells with adjust != none (absolute); R2 only H1. SE = SD between replicates / square root of the number of replicates. "Category change" = the decision (no evidence / uncertain / leakage) differs between `auc` and `fold_mean` for the same cell and metric. TOST (margin 0.02, alpha 0.05, double one-sided t-test) for R1 only on cells with >= 30 replicates.
3. **H40-1.** Cells: H1, transform raw, adjust none (all cells of A, C, GB, GC; for classifiers LRpat, RF, XGB, MLP, LSTM and NM-N0 H1 in the NM stage). Bias = fold_mean - auc per replicate; mean within a cell, then mean across cells; 95% percentile bootstrap CI (2,000) resampling replicates within a cell. Parent criterion: lower CI bound > 0.003 and |mean fold_mean - 0.5| <= 0.010. Reported per classifier.
4. **H40-3 model.** Unit = cell x transform (raw, symlog, symlogc, rank, log) x classifier RF (ET not available), H1, adjust pat, response = delta `fold_mean`. Diagnostic per cell = mean across replicates. M0: constant, lk (= log10 kurtosis), log n, log m, log p, imbalance, s, transform dummies. M1: M0 + skew + Dq05 + cusp. Ordinary OLS. Leave-one-distribution-out validation (normal, lognormal, t3, contam, chi2). Out-of-sample R2 = 1 - SSE/SST pooled over all LODO folds. Improvement dR2 = R2(M1) - R2(M0); bootstrap CI (2,000) resampling cells within distribution. "Explains better than kurtosis" = dR2 >= 0.10 and the CI does not include 0. Results that do not meet this are reported as "not supported".
5. **H40-3 cusp.** Only three cells with non-lognormal/non-contamination distributions (normal, t3, chi-square; s = 1) have a symlog delta on "light" features; a formal test of the cusp is not possible. Reported descriptively (symlog and symlogc delta with CI, cusp value, skew); the parent prediction "cusp explains" is judged as not formally tested.
6. **ROH and NM stages.** R1/R2 on `fold_mean` (ROH: mean of 50 canonical folds; NM: mean of the 5 folds of the first repetition); delta ROH = RF-logpat - RF-none; delta NM = V4 - N0; H40-1 on RF-none, LR-none, NM-N0 (H1). Soft reproduction check of NM against `hasil30/nm_paired_replikasi.csv` (rep 0-19): maximum and mean difference reported; parent criterion (<= 0.02 per replicate, mean <= 0.005).
7. **Independent check** `round40_cek_independen.py` was written after the stages finished but before the results were interpreted.
